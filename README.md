# 楦型开版工作室

浏览器里的楦头修型 + 帮面开版系统。TypeScript + three.js,楦型、版样、试穿记录全部存 IndexedDB,无需服务器。

## 运行

```bash
npm install
npm run dev        # 开发
npm run build      # 类型检查 + 产物构建
npx tsx test/geometry.check.ts   # 几何核心自检(展平精度/修型到位/放码档差)
```

## 六个页面

| 页面 | 功能 |
|---|---|
| 楦型库 | 导入 OBJ/STL,自动摆正(PCA 主轴 + 底面平面度 + 端部周长判前后),抽楦底中线断面与楦底样板曲线;漆皮/磨砂皮/网布材质预览;导出 STL 给刻楦机 |
| 楦体修型 | 跖围/跗围/兜跟围/前跷/后跷/统口宽六参数,输数或拖控制环;高斯权重过渡 + Taubin 光顺(不起棱不缩围),残差校正保证实测=设定 |
| 围度测量 | 三条标准测量线画在三维楦上,实时数值,与目标尺寸表对比,超差 ±1.5mm 标红 |
| 帮面开版 | 口门线/鞋舌线/后帮中缝等贴楦样条(吸附特征点);沿线取区域;LSCM 贴楦展平;伸长/压缩色带画回楦面,超皮料延伸率标红;切口线拆双曲面片;折边/压茬/绷帮工艺量 + 对位刀口;导出 DXF 给激光裁床 |
| 放码 | 中国鞋号(5mm/3.5mm)与欧码(6.67mm/4mm)两套规则,长度档差与围度档差分开设;整套尺码楦体一起出,跖围实测与目标逐码核对;各码楦底样板叠图;批量导出 STL |
| 试穿反馈 | 按码数记顶脚/磨跟/压背/挤趾/空跟,楦面打热点;样本积累后自动建议围度加减量 |

## 精度设计(最在意的两点)

- **展平回贴 ≤0.5mm**:LSCM 保角参数化(隐式 matvec 共轭梯度,无需矩阵库),展平后把三维测量线映射回平面比对线长,误差直接显示,超 0.5mm 提示加切口。自检中可展区域误差 0.000mm;双曲面区域靠「切口线」拆片后达标。
- **放码档差一致**:修型不是一次性缩放——先高斯权重缩放,再 Taubin 光顺,再**复测围长做残差校正**(站位间互扯,整体迭代两轮,收敛到 0.1mm 内)。自检整套 9 码跖围最大偏差 0.03mm。

## 已知简化

- 兜跟围用「跟底后点—跗面高点」斜截面近似,与手工皮尺量法略有出入
- 区域裁片的工艺量按边界点最近的画线类型自动匹配(口门→折边 5mm,接缝→压茬 8mm,底口→绷帮 15mm),暂不支持逐段手改
- 磨砂皮/网布纹理为程序化贴图示意
